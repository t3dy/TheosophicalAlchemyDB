## Paracelsus Works Summary

### Essential Primary Works
1. **Opus Paramirum** — Foundational medical-philosophical system
2. **Opus Paragranum** — Systematic treatise on medical principles
3. **Opus Paramirum de Medica Industria** — Practical medical operations
4. **Astronomia Magna** — Cosmic philosophy and astral influences
5. **Polemical theological tracts (1524-1525)** — Earliest writings; Reformation context
6. **Surgical treatises** — Wounds, fevers, miners' diseases

### Scholarly Note
- All works exist in post-mortem editions; authenticity issues important
- Dictated to secretaries (Oporinus memoir documents this)
- Scattered manuscripts; centuries of editorial work
- Distinction between authenticated and apocryphal crucial
