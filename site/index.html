About This Portal

Project Overview

TheosophicalAlchemyDB is a comprehensive digital humanities resource documenting the history and significance of Rosicrucian and spiritual alchemy traditions from the 16th to 19th centuries. It currently contains 341 entities across four entity types: historical figures, alchemical concepts, scholarly texts, and emblems.

Scholarly Framework

This portal integrates scholarship from key historians including Frances Yates, Joscelyn Godwin, Tobias Churton, Urszula Szulakowska, and Mike Zuber's definitive work on spiritual alchemy from Jacob Böhme to Mary Anne Atwood. Historiographical rigor is maintained throughout: scholarly debates are presented, not resolved; evidence gaps are acknowledged; legends are distinguished from documented facts.

Relational Browsing

Every entity links to related concepts, figures, and texts. Click any linked name inside a modal to navigate directly to that entity. Use the back button to return. The map shows publication and activity locations for all entity types.

Technology

Built with vanilla JavaScript, Leaflet.js for mapping, and a JSON database of 341 scholarly entries. All filtering, sorting, search, and relational navigation run client-side.
